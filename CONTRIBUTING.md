## How to Contribute

1. **Fork the Repository**: Create a fork under your own GitHub account.
2. **Clone Locally**:
   ```bash
   git clone https://github.com/<your-username>/my-protfolio-website.git
   cd Shambhavi-Portfolio-Website
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
5. **Develop and Test**: Verify that the application builds and runs cleanly:
   ```bash
   npm run dev
   npm run build
   ```
6. **Commit and Push**: Write clear, descriptive commit messages.
7. **Submit a Pull Request**: Provide a detailed description of the proposed changes.

## Reporting Issues

If you identify a bug, broken link, or rendering discrepancy:
1. Check the [Issue Tracker](https://github.com/shambhavijhacodes0504/my-protfolio-website/issues) to ensure the issue hasn't already been reported.
2. Open a new issue with:
   - A clear title and summary.
   - Operating system and browser version.
   - Steps to reproduce the behavior.
   - Screenshots or console logs if applicable.

> **Security Note**: Do not submit sensitive vulnerabilities through public issues. Refer to [SECURITY.md](./SECURITY.md) for private disclosure instructions.

## Suggesting Improvements

Constructive suggestions regarding UI accessibility, performance optimizations, or documentation clarity are welcome. Open an issue labeled `enhancement` outlining the problem, suggested solution, and expected benefit.

## Development Workflow

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Code Quality**: Ensure TypeScript passes with zero errors (`npx tsc --noEmit`) before opening a PR.
