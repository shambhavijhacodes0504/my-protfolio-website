# Security Policy

## Reporting Security Issues

Security and privacy are taken seriously in this project. If you discover a potential vulnerability or security concern, please report it responsibly.

### How to Report

Do **not** create public GitHub issues for security vulnerabilities.

Instead, please send an email directly to:

- **Maintainer**: Shambhavi
- **Email**: [shambhavijha0504@gmail.com](mailto:shambhavijha0504@gmail.com)
- **Subject**: `[Security] Vulnerability Report - Shambhavi Portfolio`

Please include:
1. A description of the issue and potential impact.
2. Step-by-step instructions or proof-of-concept demonstrating how to reproduce it.
3. Affected components, routes, or dependencies.

You will receive an acknowledgment within 48 to 72 hours, along with regular updates until the issue is addressed.
